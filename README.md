# Ударный БПЛА

Чёрный треугольный аппарат. Летит 30 блоков в секунду, воет на всю округу,
бьёт как три динамита и поджигает всё вокруг воронки.

## Сборка в три ступени

Сначала четыре детали, потом из них аппарат.

**Снаряд** — динамит в центре, порох в остальных восьми клетках.

**Вентилятор** — железо крестом, блок редстоуна в центре. Даёт 2 штуки за крафт.

**Фрагмент корпуса** — чёрный бетон по центральной полосе, железные слитки
по бокам. Нужно **пять штук**, то есть пять крафтов.

**Анти-глушилка** — медь по углам, громоотвод сверху, аметист в центре,
эхо-осколок снизу. Осколок добывается только в Глубокой Тьме, это самая
дорогая деталь.

**Итоговая сборка:**

```
Корпус | Корпус       | Корпус
Корпус | Снаряд       | Корпус
Вентил.| Анти-глушилка| Вентил.
```

Обычные предметы в этих клетках не сработают — рецепт требует именно
скрафченные детали, они помечены внутренней меткой.

## Как использовать

1. Правый клик по земле — аппарат встал
2. Правый клик по нему — пульт
3. «Задать координаты» — вписать в чат `X Y Z`
4. Всему серверу приходит: **«БПЛА был запущен из неизвестного места!»**

Дальше он идёт по прямой, гудит на 80 блоков вокруг и детонирует при
попадании в блок или при выходе на цель.

## Почему это видно и слышно

Аппарат специально шумный. Гул мотора на низком тоне плюс периодический свист,
громкость 5.0 — слышно издалека. Это даёт защищающимся шанс: успеть заметить
и сбить стрелой или из пулемёта.

## Модель

Не моб, а `ItemDisplay` — блок угля, сплющенный до толщины 0.16 и повёрнутый
на 45°. Сверху читается как треугольное крыло. Рядом летит невидимый стенд —
он принимает попадания, потому что дисплеи урон не получают.

Любой блок подойдёт, меняется в конфиге:

```yaml
model:
  material: "COAL_BLOCK"    # или BLACK_CONCRETE, OBSIDIAN
  scale-x: 1.4
  scale-y: 0.16
  rotation-degrees: 45
```

## Имя

Меняется в двух местах и применяется без пересборки:

```yaml
item:
  name: "&8&lБПЛА"          # имя предмета
model:
  display-name: "&8БПЛА"    # имя над аппаратом в мире
```

В сообщении о запуске подставляется `{name}`.

## Команды

- `/uav give [ник] [кол-во]` — выдать готовый аппарат
- `/uav part <деталь> [ник]` — выдать компонент (WARHEAD, FAN, HULL, JAMMER)
- `/uav boom` — подорвать свои аппараты
- `/uav reload` — перечитать конфиг и рецепты

## Важно для сервера

По умолчанию **ломает блоки и поджигает**. На сервере с постройками это
выжжет всё за пару запусков:

```yaml
explosion:
  break-blocks: false
  set-fire: false
  extra-fire-radius: 0
```

Ещё есть защита спавна (`spawn-radius: 80`) и перезарядка 60 секунд
между запусками.

## Технические мелочи

На 30 блоках в секунду шаг больше одного блока, поэтому столкновения
проверяются подшагами по 0.4 блока — иначе аппарат пролетал бы сквозь стены.

Сглаживание движения включено через интерполяцию дисплея. На серверах
старее 1.20.2 метод недоступен, плагин это переживёт, но движение будет резче.
